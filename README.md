# Intonation Coach

これは、音声ファイルのピッチ（イントネーション）をグラフ化するとともに、マイクから録音した音声のピッチと比較することでフィードバックを可能にするというものです。

## 特徴
* ウェブアプリなのでインストール不要で実行できます。
* ピッチの推定は、SwiftF0という畳み込みニューラルネットワーク（CNN）を使用しています。
* 音声処理はすべてブラウザ内で行われ、外部サーバーには送信されません（音声データはすべてメモリ上に展開されます...このため大きなファイルは不得手です）。

## 使い方
### 音声ファイルの入力、再生
1. ［ファイル選択］ボタンを押し、読み込ませたいファイルを指定する。→読み込みが完了するとオシログラムが表示されます。
2. ［再生/停止］ボタンを押すことで、再生や停止が可能です。
	* 再生中にはオシログラム上に赤線が表示されます。

### オシログラム上の操作
* オシログラムの好きな部分をクリックすることで再生開始位置を動かすことができます（停止時、再生時とも）。
* オシログラムの範囲をドラッグすることで、再生範囲を指定でき、再生範囲を指定し、［再生/停止］ボタンを押すと、その範囲内での再生が可能です。
* オシログラムの波形を拡大するには［拡大(+)］、縮小するには［縮小(-)］、ファイル全体の波形を見るには［全体表示リセット］をクリックします。
* 波形拡大時、表示されている波形よりも前や後の波形を表示するにはそれぞれ、［◀］［▶］ボタンをクリックします。

### 音声のピッチ分析
* オシログラムをドラッグし、必要な範囲を選択後、［選択範囲を切り出し＆分析］ボタンをクリックすると画面下部にピッチチャートが青色で表示されます。
* ピッチ分析の確信度を低くすると、ピッチ推定時に切り捨てられた微妙なピッチも表示されますが、正しくない結果も表示されます。なお、［信頼度 ≧］と表示された部分をクリックするとデフォルトの信頼度（0.90）に戻ります。
* ピッチチャート上に切り出した音声を再生するには、［分析範囲生成/停止］ボタンを使用します。

### マイクから入力した音声の分析
* ［マイク録音］ボタンを押すと、押している間だけマイクからの音声を録音し、離すと同時に分析結果がオレンジ色で表示されます。こちらにも信頼度があり調整可能です。
* ピッチチャートをドラッグすることで、オレンジの分析結果を左右に動かすことができるため、モデル音源とのタイミングを合わせることができます。なお、ピッチチャートをダブルクリックすると、元の状態に戻ります。

### 抽出音源のファイル出力
* ［WAVファイル出力］を押すとピッチチャート上の音声（青色で表示された方）をWAVファイルとして出力できます。なお、Shiftキーを押しながらこのボタンを押すと、WebM形式での出力となりますが、その出力処理は「再生しながらの作業」となるので10秒間の抽出音声を出力するには10秒強待つことになります。

### 抽出音源の分析結果出力
* ピッチチャートの表示に使用したデータをCSV形式で出力します。その形式は以下の通りです（1行目は見出し行です）。
	* フレーム通番（0からの連番）
	* 抽出部分冒頭からの経過時間（秒）
	* モデル音源全体からの経過時間（秒）
	* ピッチ推定結果（Hz）
	* 確信度
	* 無声/有声の別（0|1）

## 技術情報、その他
* ピッチ推定アルゴリズムは、SwiftF0を採用し、ONNX+ORTを使用して実装しています。
* AI生成によるコードを一部使用しています（内容は検証済み）。
* URLパラメータに lang=eng を追加するとメッセージが英語化されます。
